SCHEDULER STUDIO — DUPLICATE RUN POPUP FIX
========================================

The active index.html no longer calls JavaScript confirm() for RUN, RESTART,
RUN-AND-ANSWER, ENABLE, or DISABLE actions. Direct task actions proceed through
the dashboard/API workflow; ambiguous task matching is handled by the agent's
chat clarification rather than a browser modal.

Native confirmations intentionally remain for destructive task deletion and
for the optional GPT-4o mini task-description generation action.

IMPORTANT: The prior popup text "Queue a run request for ...?" belonged to an
older HTML backup (index_before_llm_voice.html). That backup is deliberately
excluded from this ZIP to avoid opening the outdated page by mistake.

Install:
1. Stop the old dashboard API with Ctrl+C.
2. Extract this ZIP to a new folder.
3. Run run_dashboard.bat from the extracted RuleBasedSchedulerDashboard folder.
4. Visit http://127.0.0.1:8765 and press Ctrl+F5.
5. Verify the new build is serving by searching the active page source for
   "Do not use a native browser confirm here" or checking that this file is
   absent from the active HTML: "Queue a run request for".

The existing LangGraph scheduler is not modified. Only run the dashboard API
from this extracted folder, and ensure DB_PATH points to the same SQLite file.
